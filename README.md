# AI Personal Context Profile

This repository stores my personal preferences, communication style, working habits, and boundaries so AI assistants and agents can collaborate with me effectively.

## Agent Startup Contract
- **When:** At the start of every important project or conversation, before doing substantive work.
- **What:** Read this repository from `main` and apply the files in the reading order below.
- **Source of truth:** This repo. Local mirrors (for example WorkBuddy `USER.md` / `MEMORY.md`) are convenience copies; if they conflict, follow this repo and flag the difference.
- **Sync-back:** When a method, habit, tool, or boundary is confirmed or changed during work, update the corresponding file(s) in this repo in the same session, preserving existing content and using a descriptive commit message.

## Reading Order for AI / Agents
1. Read `communication-style.md` first to match response format and tone.
2. Read `workflows-and-habits.md` for tools, coding/writing conventions, and daily habits.
3. Read `identity-and-values.md` for decision principles and hard boundaries.
4. Use `profile.json` when structured key-value preferences are needed.

## Safety & Privacy Note
Do not assume or infer private data not explicitly written here. Ask before taking external or destructive actions.
